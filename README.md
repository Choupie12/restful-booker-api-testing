# Restful Booker API Testing Project

## Project Overview

This project demonstrates manual API testing using Postman on the Restful Booker application.

The objective was to validate API endpoints, verify response data, perform positive and negative testing, and document defects identified during testing activities.

## Scope

The following endpoints were tested:

* GET /booking
* GET /booking/{id}
* POST /booking
* PUT /booking/{id}

## Testing Activities

* API request execution
* HTTP status code validation
* Response time validation
* JSON response verification
* Positive testing
* Negative testing
* Defect documentation

## Tools Used

* Postman
* GitHub
* Excel
* JSON

## Key Results

* Successful validation of booking retrieval endpoints
* Successful creation of bookings through POST requests
* Validation of response structure and business data
* Identification of an authentication/update issue resulting in HTTP 403 responses during PUT requests
