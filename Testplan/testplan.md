# API Test Plan

## Project Name

Restful Booker API Testing

## Objective

The objective of this project is to validate the functionality, reliability and performance of the Restful Booker API using Postman.

## Scope

The following endpoints are included in testing:

* GET /booking
* GET /booking/{id}
* POST /booking
* PUT /booking/{id}

## Testing Types

* Functional Testing
* Positive Testing
* Negative Testing
* Response Validation
* Performance Validation

## Test Environment

Tool: Postman

API: Restful Booker

Format: JSON

## Deliverables

* Test Cases
* Bug Reports
* Postman Collection
* Screenshots
* Test Summary Report

## Entry Criteria

API endpoints available and accessible.

## Exit Criteria

All planned test cases executed and documented.
